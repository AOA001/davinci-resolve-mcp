# Opt-in: serve SKILL.md skills to clients over MCP (Skills over MCP,
# io.modelcontextprotocol/skills). Needs Python 3.11+.
#
#   venv/bin/pip install -r requirements-skills.txt
#
# This replaces the v1 `mcp` SDK with mcp 2.x underneath fastmcp 4, and
# src/utils/mcp_sdk.py then picks the "fastmcp4" backend on its own. Skills come
# from <project>/.claude/skills plus any folders in DAVINCI_MCP_SKILLS_DIRS
# (os.pathsep-separated); DAVINCI_MCP_SKILLS=0 turns them off. Networked
# transports (sse / streamable-http) still need the v1 SDK, so for those set
# DAVINCI_MCP_SDK=mcp1 with the default requirements.txt install.
fastmcp>=4.2.6,<5
